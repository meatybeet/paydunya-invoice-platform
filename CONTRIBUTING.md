# Contributing

Thanks for contributing to PayDunya Invoice Platform.

1. Fork the repository and create a focused branch from `main`.
2. Install the backend requirements and run the application locally.
3. Keep changes small, document any new configuration, and never commit keys,
   `.env` files, or other credentials.
4. Open a pull request explaining the problem, the solution, and how you
   tested it.

By contributing, you agree that your work may be distributed under the MIT
License.
